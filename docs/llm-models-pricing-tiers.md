# LLM Models Pricing Tiers

## Overview
This document provides a comprehensive list of available AI models from OpenAI and Anthropic APIs, organized by pricing tiers.

## OpenAI Models

### Basic Tier (Most Cost-Effective)
- **gpt-3.5-turbo**: $0.50 per 1M input tokens, $1.50 per 1M output tokens
  - Fast, cost-effective for general tasks
  - 16K context window
- **gpt-3.5-turbo-0125**: Latest GPT-3.5 Turbo model
- **gpt-3.5-turbo-1106**: Previous stable version

### Standard Tier (Balanced Performance)
- **gpt-4o-mini**: Most cost-effective GPT-4 level model
  - Optimized for efficiency
  - Good balance of cost and capability
- **gpt-4.1-nano**: Fastest, most cost-effective for low-latency tasks
- **gpt-4.1-mini**: Affordable model balancing speed and intelligence

### Premium Tier (Most Capable)
- **gpt-4**: $30 per 1M input tokens, $60 per 1M output tokens
  - Most capable for complex tasks
  - 8K context window (standard)
- **gpt-4-turbo**: Latest GPT-4 Turbo with vision capabilities
  - 128K context window
  - Supports image inputs
- **gpt-4-turbo-preview**: Preview of GPT-4 Turbo features
- **gpt-4-0613**: Stable GPT-4 version
- **gpt-4-32k**: Extended context window (32K tokens)
- **gpt-4-32k-0613**: Stable 32K context version
- **gpt-4.1**: Smartest model for complex tasks

### Reasoning Models (Special Purpose)
- **o4-mini**: Cost-efficient reasoning model
  - Optimized for math, coding, and multi-step reasoning
- **o3**: Most powerful reasoning model (when available)
  - Leading performance on complex reasoning tasks

## Tier Recommendations

### Basic Tier Use Cases
- High-volume, simple tasks
- Chatbots with straightforward conversations
- Basic content generation
- Quick responses where cost is primary concern

### Standard Tier Use Cases
- Production applications requiring reliability
- Complex conversations
- Code generation and debugging
- Content creation with quality requirements

### Premium Tier Use Cases
- Complex reasoning and analysis
- High-stakes decision making
- Advanced creative tasks
- Research and development
- Tasks requiring maximum accuracy

## Additional Considerations

1. **Context Windows**: All Claude models support 200K token context windows
2. **Batch Processing**: Both providers offer 50% discounts for batch processing
3. **Prompt Caching**: Available for reducing costs on repeated prompts
4. **Rate Limits**: Higher tier models typically have lower rate limits
5. **Availability**: Some models may have limited availability based on demand

## Cost Optimization Tips

1. Start with basic tier models and upgrade only when needed
2. Use prompt caching for repetitive tasks
3. Consider batch processing for non-real-time workloads
4. Monitor token usage to optimize prompts
5. Use appropriate models for each task type
